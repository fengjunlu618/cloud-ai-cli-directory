命令行工具名录 一份按“管什么”而不是按“谁家的”编排的 CLI 索引。先分清它管机器还是管模型，再决定装哪一个。

近两年“CLI”这个词被两种完全不同的东西共用：一类是云厂商用来管服务器、存储、网络的运维工具；另一类是模型厂商给 AI Agent 用的执行入口，装进 Cursor、Claude Code 就能读写文档、生成图视频。命令名相似、能力不重叠，混装会白折腾。
